# Mboa

Mboa est une plateforme de confiance pour la location de logements au Cameroun : annonces gratuites, biens vérifiés, visites, réservation et contrat numérique.

- Site : [mboacm.com](https://mboacm.com)
- Réseaux : @mboa_cm

Le code de Mboa est privé. Pour signaler une faille de sécurité, voir [SECURITY.md](../SECURITY.md).
